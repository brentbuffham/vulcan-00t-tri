## PROVEN FORMAT FACTS (intercepts, GT-verified — do not re-derive)
1. **Unified token grammar** spans coords AND faces:
   - `V-token`: prefix p<0x20 → nb=(p&7)+1 payload bytes. Prefix hi-bits are
     NOT length/depth (ruled out at 53%); their meaning still open.
   - `T-token`: byte ≥0x20 + arg byte. In coords arg ≡7 mod 8; T1 low-5 and
     T2 hi-5 bits = ~10 signal bits per scalar (placement/event live here).
   - `E-token`: 0xE0..0xFF + 2 args. `e0 03 00/15` = face record separators;
     `e0 03 14` = W1 section marker. One language everywhere.
   - `FULL`: literal 8-byte BE double; lead byte 40/41/C0/C1 is just the IEEE
     exponent byte of world coords (X→40 EB, Y→41 03/04, Z→40 84 here).
   - **Zero-padding runs** (W3): ≥6 consecutive 0x00 = padding, strip it.
     Two in intercepts: 227B @33541, 253B @59146, each followed by
     `18 63 00 00 15 64 00 00 1f` + re-anchor FULLs (sub-object boundary? the
     id-like prefix is undecoded).
2. **Emission order = vertex-major X,Y,Z**, strict forward cycle; FULLs occupy
   their band's slot and resync the cycle. Token count ≈ 3·NV exactly.
   (stream_group.py: posY−posX=+1, posZ−posX=+2. June's "mesh-traversal
   scrambled order" was decode noise, not format.)
3. **Delta = byte-window splice onto a reference**: value = ref-prefix +
   payload + ref-suffix. Windows end at byte 7 or 8 (occasionally 6);
   payloads may carry 1–2 leading patch bytes (sub-mm refinements of the
   previous axis). **Reference = previous same-axis value in ~93%**, FULLs
   re-anchor (reference_rule.py — Mystery C resolved as prev1-dominant).
4. **Placement is locally signaled**: on register-free CERTAIN labels
   (fingerprint2.py) the (p,T1,T2)→placement table is **99.9% pure** and the
   cycle transition is pure-forward. The signal exists; it just hasn't been
   extracted as a clean bit formula yet (see BLOCKER).
5. **Events (~5% of tokens)**: split payloads (two scalars in one token,
   consecutive phases), refines (extra token, no advance), 2-token values.
   These shift the cycle phase and MUST be signaled in the bytes (Vulcan
   decodes them) — signature unknown = part of the blocker.
6. **Z-grid label noise** poisoned every naive analysis: Z spacing ~6mm ⇒
   ~20% coincidental grid hits at 0.6mm tol. NEVER trust Z-only evidence;
   verify via full triples or X/Y (both ~unique per vertex: 2970/2972 of 2975).

## METHODOLOGY LESSONS (07-03, hard-won)
- Value-space comparisons, never byte-equality vs mm-rounded GT (bytes 4+ differ).
- Token-level hit rates lie (Z floor); only full-triple/vertex-identified
  metrics count.
- Long background beams get killed in this environment; prefer sequential
  solvers with small state. The 397MB cands_cache.pkl in scratchpad is disposable.
- Registers must carry SPLICED bytes (never GT-snapped) for exact cascades —
  but rounded anchors are fine as resync approximations (error ≤1e-7 m).
