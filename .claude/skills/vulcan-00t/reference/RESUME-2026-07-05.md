## NEW PROVEN FACTS (2026-07-04, all GT-verified via commit-label harvest)
1. **Placement window = exact changed-byte span** (delta_mechanism.py):
   payload replaces bytes [k0,k0+nb); window starts at first changed byte
   (100%), ends at last changed byte (99.7%). r=0 ALWAYS (leading-patch model
   dead).
2. **k0 is signaled in T1** (t1_k0_map.py, k0_rule.py): T1 0x21-0x3F -> k0=2;
   0x40-0x5F -> k0=3; T1==0x20 -> k0=3 if T2<0x60 else 2. 98.2% on clean
   labels. (A flipped rule from the mech-census was tested and REFUTED —
   0.2% vs 1.7% end-to-end; census had first-hit selection bias.)
3. **Carry-splice is real** (fail_families.py, relabel.py): byte k0-1 changes
   by +-1 (borrow/carry past the window), ~606 tokens. Also older-reference
   splices (prev2..prev6 / last FULL of axis, ~250) and escape-lead payloads
   (payload[0] in 0x00-0x1F/0xF0-0xFF stripped, then splice on older ref).
4. **353 escape-prefixed FULLs** (notk0.py): 1 byte >=0x20 + sane 8-byte BE
   double, hidden throughout the coord region (old tokenizer shredded them
   — a major desync source). FULL-runs (consecutive raw doubles Z,X,Y,...)
   directly follow the seed triple at 8350-8422 (hexdump_start.py).
5. **V-prefix hi bits ANNOUNCE following FULLs** (p_hi_fulls.py): p>>3 =
   number of FULL doubles immediately after this V-token, 97.8% exact.
   A FULL occupies a cycle slot IFF announced; unannounced = re-anchor.
   THIS is the framing/occupancy signal — not the escape prefix.
6. **V->V transitions are 99.6% pure +1 cycle** (trans_rule.py). ALL phase
   chaos concentrates at FULL neighborhoods + 81 event sites.
7. Answer-key caveat: labels flagged lenY/lenZ/yid2/resync have fb bytes that
   are GT-ROUNDED approximations (e.g. ...70a3d70a3d tails) — byte-true only
   where matches nonempty. Don't mine byte mechanisms from the approx ones.
