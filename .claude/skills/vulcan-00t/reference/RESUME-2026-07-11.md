## WHAT CHANGED (verified, reproduced bit-exact, commit e8e7e9d, pushed)

The topology vertex-REF decode was **wrong** since 2026-07-05. The old
`topo_rails.py:29` splice `r = (prev_ref & ~0xFF) | pp` fabricated **~1600
phantom refs**:
- `00 pp` with `pp < 0x80` is a **STRUCTURAL field, not a ref** (~1425 of them,
  they chain / zero-fill). The old rule made each a phantom ref with a stale
  high byte — source of the round-number refs (0,1536,2048,2816…).
- The `0x02..0x06 → (b+1)-byte` rule **swallowed real refs and even `e0 03`
  delimiters** (→ the fake 57–117-"ref" monster groups).

### The correct rule (Opus-implementable; in REF_INDEX_DECODE.md §THE CORRECT RULE)
```
per group: 'e0/e1 xx' delim ; 0x00 marker (skip 1) ;
  first token: lead>=0x20 -> first-op (2B, arg=phase field)
               lead==0x01 -> header triple '01 hh ll' -> NON-FACE group, no refs
  body: '01 hh ll'       -> ABSOLUTE ref, big-endian, accept 1..2974
        '00 pp' pp>=0x80  -> SHORT ref: value = nearest-congruent(prev_ref, pp)
        '00 pp' pp<0x80   -> structural, NOT a ref (skip 2)
        0x02..0x06        -> unknown, skip 1
        0x08..0x1f        -> pad, skip 1
        else              -> op, skip 2
```
